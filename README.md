# 📚 AI Math Problem Classifier

> Embedding + Cosine Similarity + GPT를 활용한 고등학교 수학 문제 자동 분류 프로그램

---

## 📖 프로젝트 소개

새로운 수학 문제가 입력되면 교육과정의 차시를 자동으로 분류하는 AI 프로그램입니다.

이 프로젝트는 임베딩과 코사인 유사도를 이용해 가장 유사한 차시 후보를 먼저 추출한 뒤,
GPT가 최종적으로 가장 적절한 차시를 선택하는 2단계 분류 방식을 사용합니다.

---

```text
분류할 문제 임베딩 생성

        ↓
결과 엑셀 다운로드
```

## ▶ 실행 방법

### 1. 저장소 복제

```bash
git clone https://github.com/jj0-311/math-problem-classifier.git
```

### 2. 프로젝트 폴더로 이동

```bash
cd math-problem-classifier
```

### 3. 가상환경 생성

```bash
python -m venv venv
```

### 4. 가상환경 활성화

Windows PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

Windows CMD:

```cmd
venv\Scripts\activate
```

### 5. 필요한 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 6. 환경변수 설정

`.env.example` 파일을 복사하여 `.env` 파일을 만들고, 자신의 OpenAI API 키를 입력합니다.

```env
OPENAI_API_KEY=your_api_key_here
```

### 7. 프로그램 실행

```bash
python -m streamlit run app.py
```

## 🔎 문제 해결 과정

### 1. 코사인 유사도만으로 세부 차시를 구분하기 어려운 문제

처음에는 분류할 문제와 기준 대표 문제의 임베딩을 생성한 뒤, 코사인 유사도가 가장 높은 차시를 최종 결과로 선택하려고 했습니다.

하지만 테스트 과정에서 서로 비슷한 개념을 다루는 차시들의 유사도 값이 비슷하게 나타났고, 유사도가 가장 높은 결과만으로는 문제의 핵심 개념과 풀이 방법을 세부적으로 구분하기 어려웠습니다.

이를 해결하기 위해 코사인 유사도는 최종 분류가 아니라 관련성이 높은 후보 차시 5개를 추출하는 데 사용했습니다. 이후 GPT가 각 후보의 차시명, 대표 문제, 분류기준, 제외기준을 비교하여 최종 차시를 선택하도록 2단계 분류 구조로 개선했습니다.

---

### 2. 같은 차시가 Top 5 후보에 반복되는 문제

처음에는 기준 대표 문제의 유사도를 높은 순서대로 정렬하여 Top 5를 추출했습니다.

하지만 하나의 차시에 여러 대표 문제가 등록되어 있어, 같은 차시에 속하는 기준 문제들이 Top 5 안에 반복해서 포함되는 경우가 발생했습니다. 이 경우 GPT가 실제로 비교할 수 있는 차시의 종류가 줄어드는 문제가 있었습니다.

이를 해결하기 위해 유사도순으로 정렬한 뒤 차시 ID를 기준으로 중복을 제거하고, 서로 다른 차시 중에서 상위 5개를 추출하도록 수정했습니다.

---

### 3. 다운로드 버튼을 누르면 분류 결과가 사라지는 문제

초기 웹 버전에서는 분류가 완료된 뒤 결과표와 다운로드 버튼이 정상적으로 표시되었지만, 다운로드 버튼을 누르면 화면이 다시 실행되면서 분류 결과가 사라졌습니다.

Streamlit은 사용자가 버튼을 누르거나 화면의 입력값을 변경할 때마다 전체 코드를 위에서부터 다시 실행하기 때문에 발생한 문제였습니다.

이를 해결하기 위해 분류 결과 DataFrame과 엑셀 다운로드 데이터를 `st.session_state`에 저장했습니다. 이후 화면이 다시 실행되더라도 저장된 결과를 불러오도록 하여, 두 개의 결과 파일을 연속으로 다운로드할 수 있도록 개선했습니다.

---

### 4. 기준 대표 문제를 반복해서 임베딩하는 문제

기준 대표 문제는 자주 변경되지 않지만, 프로그램을 실행할 때마다 모든 대표 문제의 임베딩을 다시 생성하고 있었습니다.

이로 인해 같은 기준 파일을 반복해서 사용할 때도 처리 시간이 발생하고, 동일한 내용에 대해 OpenAI Embedding API를 불필요하게 다시 호출하는 문제가 있었습니다.

이를 해결하기 위해 대표 문제의 실제 문장 목록과 임베딩 모델명을 기준으로 디스크 캐시를 적용했습니다. 파일명이 달라도 대표 문제의 내용과 순서가 같다면 기존 임베딩을 재사용하고, 문제 내용이나 임베딩 모델이 변경된 경우에만 새로 임베딩하도록 개선했습니다.

## 🛠 개선 사항

- 콘솔 실행 방식에서 Streamlit 웹 인터페이스로 확장
- 중간 임베딩 엑셀 파일 저장 과정 제거
- 분류 로직과 웹 화면 코드를 별도 파일로 분리

- 진행률 바와 작업 상태 문구 추가
- 필수 열, 빈 셀, 잘못된 GPT 응답에 대한 오류 처리 추가
- `st.session_state`를 이용해 다운로드 후에도 결과 유지
- 대표 문제 임베딩에 디스크 캐시를 적용해 반복 API 호출 감소
- `.env`를 이용해 API 키를 소스코드와 분리
